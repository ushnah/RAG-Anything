# Image and video scene search

The **Images & scenes** collection searches visual descriptions generated by local Qwen2.5-VL, plus separately identified source labels. BGE-M3 embeds these texts and ranks them against Arabic or English queries. Results contain the original image or a video player seeking to the sampled frame. Select **Images only** or **Video only** to enforce the requested format.

This is a description-based visual retrieval baseline alongside the existing LightRAG question-answering pipeline. It does not yet embed pixels directly or analyze motion across frames. It bypasses answer generation for “show me” requests: results are candidate media, not generated claims that a landmark has been verified. Similarity is not calibrated confidence, and the top candidates may be irrelevant when the requested landmark is absent.

## Public samples

- `data/visual_samples/king_abdul_aziz_gate.jpg`: [King Abdul Aziz Gate](https://commons.wikimedia.org/wiki/File:King_Abdul_Aziz_Gate_-_panoramio.jpg), khadim-un-nabi Rao, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Original unmodified download. Arabic/English identity label is derived from the publisher's description, not inferred by Qwen.
- `data/visual_samples/makkah.webm`: [Great Mosque of Mecca, February 4, 2010](https://commons.wikimedia.org/wiki/File:Great_Mosque_of_Mecca_(video)_-_Feb_4,_2010.webm), Habib-Ur-Rehman Janjua, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Original unmodified download. Approximately 61 seconds. Sampled frames show the mosque courtyard, crowds, and the Kaaba. **This is not verified footage of King Abdul Aziz Gate.**

Sidecars retain attribution, license links, hashes, and label provenance. Labels identify the whole asset; they cannot establish that a particular landmark is visible at each timestamp.

## Build and run

```sh
.venv311/bin/python -m arabic_poc.visual build data/visual_samples --frame-seconds 20
.venv311/bin/python -m arabic_poc.web
```

Open http://127.0.0.1:8765 and choose **Images & scenes**.

Example queries:

- Images only: `أرني صورة باب الملك عبد العزيز في مكة`
- Images only: `Show me King Abdul Aziz Gate in Makkah`
- Video only: `أرني فيديو لساحة المسجد والحشود ليلاً`
- Video only: `Show me the Kaaba in the video`

Asking for a **video** of King Abdul Aziz Gate cannot be verified from these samples. Do not present the generic mosque video as an exact gate match.

The vision model must have both safetensors shards. Each build replaces the visual index only after all descriptions and embeddings succeed. Rebuild all desired files together. The small POC index stores vectors in JSON; this is not intended as a large-scale vector store. A 20-second sampling interval can miss short appearances. Existing speech collections are unchanged.

## Actual validation

Local Qwen2.5-VL-3B generated five descriptions: the gate photo and video frames at 0, 20, 40, and 60 seconds. BGE-M3 generated the searchable index. The vision run required Mac GPU access outside the Codex sandbox; the sandbox CPU attempt exited with code 137 while loading weights.

Two live HTTP queries completed: Arabic gate-image search in 10.5 seconds and English Kaaba-video search in 9.5 seconds. All returned media obeyed the selected image/video filter; their HTTP byte-range requests succeeded. These are tiny-corpus smoke tests, not retrieval-accuracy measurements. Twenty regression checks passed, and JavaScript syntax was checked. No browser visual QA was performed.

**Vision quality is limited:** the gate photo description confuses minarets with domes and speculates about weather. The 40-second mosque frame is wrongly described as a sports stadium; other frame descriptions also contain errors. The original model outputs are preserved in [validation/visual_extraction.json](validation/visual_extraction.json). Live responses are in [validation/visual_query_checks.json](validation/visual_query_checks.json). Exact landmark recognition and motion understanding have not been established.
